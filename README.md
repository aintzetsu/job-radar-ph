# Job Radar PH

A job-search dashboard for Philippine and remote roles.

[Open the live site](https://job-radar-ph.vercel.app)

- Browse live employer listings and refresh them every five minutes.
- Rank roles using pasted resume text, generate editable application drafts, and track applications and follow-ups.
- Guest progress is saved in the browser.

## Local development

Serve this directory with a static HTTP server, such as `python -m http.server 8000`, and open `http://localhost:8000`.
